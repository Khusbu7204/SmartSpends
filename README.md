# SmartSpend - AI Expense Tracker
*Track, Analyze, and Save Smarter*

## Overview
SmartSpend is an AI-powered expense tracking application that helps users monitor their spending habits, analyze patterns, and receive smart saving recommendations. Built with Python and Streamlit, it provides an intuitive interface for managing personal finances.

## Features
- **Expense Tracking**: Log daily expenses with date, amount, category, and payment method
- **Visual Analytics**: 
  - Pie charts showing spending distribution by category
  - Bar charts displaying monthly spending trends
- **AI-Powered Analysis**: 
  - K-means clustering to classify spending behavior
  - Smart saving tips based on spending patterns
- **Simple CSV Storage**: All data stored locally in CSV format
